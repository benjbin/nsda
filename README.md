## Identité en bref

**Monogramme Relais** — un N, puis un S qui avance en laissant une trace de trois échos ambre : la nuit passe le relais à la suivante.

**Wordmark** — NIGHT (Anybody, largeur 150, graisse 900) + SQUARE (graisse 280), suivi d'un carré arrondi qui porte la même trace.

**Couleurs**

| Nom | Hex |
|---|---|
| Nuit | `#0B0908` |
| Ivoire | `#EFE6DA` |
| Cire | `#CDBBA5` |
| Voile | `#ADA093` |
| Tabac | `#3A2A22` |
| Ambre | `#B5683C` |
| Échos de la trace | `#D2A78B` · `#B5683C` · `#683D25` |

**Typographies** — Anybody (titres), Hanken Grotesk (texte), Martian Mono (infos, chiffres).
